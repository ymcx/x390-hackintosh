# OpenCore EFI for the Thinkpad X390

Not working due to not being needed:
- Bluetooth
- Ethernet
- [Analog audio](https://dortania.github.io/OpenCore-Install-Guide/extras/tahoe.html#analog-audio)
  - My USB-C headphones seem to be working just fine via digital audio, even without AppleALCU for some reason.

Not testested:
- Hibernation

Wi-Fi is working as long as you install [HeliPort](https://github.com/OpenIntelWireless/HeliPort) after installation. During installation you may use USB tethering to connect to the internet.
